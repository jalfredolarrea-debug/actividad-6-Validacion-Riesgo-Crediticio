# Instrucciones de carga por navegador — sin subir ZIP

1. Entra a https://github.com/new.
2. Nombre sugerido: `actividad-6-validacion-riesgo-crediticio`. Descripción: `Evaluación y validación académica de modelos de clasificación crediticia sobre South German Credit`.
3. Selecciona **Public** si deseas entregar un enlace consultable sin credenciales. Deja desmarcada la creación automática de README y .gitignore (ya vienen incluidos).
4. Elige **Create repository**.
5. En la página del repositorio vacío elige **uploading an existing file**, o **Add file > Upload files** si GitHub presenta esa opción.
6. Desde tu computadora, arrastra al área de carga **el contenido** de la carpeta `Actividad_6_GitHub_Repositorio` (el notebook, README, requirements, `.gitignore` y las carpetas `docs` y `actividad6_resultados`). GitHub admite arrastrar carpetas; verifica que las rutas se conserven en la previsualización.
7. Escribe el mensaje de commit: `Actividad 6: notebook, resultados y trazabilidad` y confirma la carga en la rama principal.
8. Abre el repositorio en una pestaña de incógnito. Comprueba que aparecen `README.md`, `Actividad_6_Notebook_Final.ipynb`, `docs/` y `actividad6_resultados/`; entra al notebook y a una imagen PNG.
9. Guarda el enlace del repositorio para el reporte técnico. Añade el reporte cuando quede concluido.

**Protección de datos:** no agregues credenciales de GitHub, tokens, información bancaria privada, contraseñas ni datos de clientes reales. No es necesario publicar el ZIP original de UCI: el notebook lo descarga desde la fuente oficial.

**Nota:** Si tu equipo bloquea descargas comprimidas, no necesitas subir un archivo ZIP: descarga los archivos individuales desde esta conversación y utiliza el respaldo de Colab que ya conservas para los PNG/CSV/JSON. GitHub admite hasta 100 archivos por carga en su interfaz web (límite ordinario de 25 MiB por archivo).
